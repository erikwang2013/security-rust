# security-rust

**🌐 [中文 (原文)](../../README.md)**

Библиотека обнаружения атак, написанная на Rust, охватывающая 27 детекторов в 4 категориях: инъекционные атаки, протокольные атаки, атаки на данные/сериализацию, утечки файлов/чувствительных данных. Ноль внешних зависимостей фреймворков — чистое сканирование строк.

---

## Идея дизайна

### Почему «обнаружение», а не «блокировка»

Библиотека позиционируется как **чистый сканер ввода** — принимает строку, возвращает структурированный результат обнаружения. Она не привязана ни к какому веб-фреймворку, не разбирает HTTP-запросы/ответы, не выполняет блокировку в реальном времени. Так вы можете встроить её в любой конвейер: движок правил WAF, аудит логов, предварительную проверку API-шлюза, CLI-инструменты сканирования безопасности и т.д.

### Принципы архитектуры

- **Единая ответственность** — каждый детектор отвечает только за один тип атаки и внутри хранит скомпилированные наборы регулярных выражений
- **Единый интерфейс** — trait `Detector` — единственный контракт для всех детекторов: `fn detect(&self, input: &str) -> Option<DetectionResult>`
- **Покрытие по умолчанию** — `Scanner::default()` одним вызовом собирает все 27 детекторов, готов к использованию без настройки
- **Опциональная настройка** — `Scanner::builder()` поддерживает настройку по требованию: выборочная сборка детекторов через `.with_detector()`

### Компромиссы

| Решение | Выбор | Причина |
|---------|-------|---------|
| Регулярные выражения vs парсер | Регулярные выражения | В сценариях обнаружения скорость важнее; регулярные выражения лучше покрывают обфусцированные/обходимые паттерны |
| Первое совпадение vs полное сканирование | Полное сканирование | Один ввод может одновременно запускать несколько атак; нельзя допускать пропуск |
| Ноль зависимостей vs подключение serde | Ноль зависимостей | Зависит только от `regex` + `thiserror` — быстрая компиляция, малый размер |

### Ответственность модулей

| Модуль | Путь | Кол-во детекторов | Ответственность |
|--------|------|-------------------|-----------------|
| Ядро | `src/lib.rs` `result.rs` `scanner.rs` | — | Trait `Detector`, `DetectionResult`, `Scanner`/`ScannerBuilder` |
| Инъекции | `src/injection/` | 10 | XSS, SQL-инъекции, инъекции команд, NoSQL, LDAP, XPATH, JNDI, SSI, GraphQL, SSTI |
| Протокол | `src/protocol/` | 9 | SSRF, XXE, инъекция заголовков, атака на Host-заголовок, контрабанда запросов, открытое перенаправление, CORS, WebSocket, DNS-ребандинг |
| Данные | `src/data/` | 5 | Десериализация PHP, CSV-формульная инъекция, инъекция в заголовки почты, атаки на JWT, загрязнение прототипа |
| Файлы | `src/file/` | 3 | Обход пути, вредоносная загрузка файлов, утечка чувствительных данных |

### Структура результата обнаружения

`DetectionResult` структурированно возвращает шесть полей: `attack_type`, `category`, `severity`, `matched_pattern`, `offset`, `message`. Полное определение см. в [Справочнике API](./API.md).

## Реализованные функции

### Инъекционные атаки (10 детекторов)

| Детектор | Покрываемые паттерны | Серьёзность |
|----------|----------------------|-------------|
| **xss** | `<script>`, обработчики событий `onerror=` и др., псевдопротокол `javascript:`, теги `<svg>`/`<iframe>`, CSS `expression()`, `eval()`, `document.cookie` | Critical |
| **sql_injection** | `UNION SELECT`, инъекции с задержкой `sleep()`/`benchmark()`/`pg_sleep()`, перечисление `information_schema`, хранимые процедуры `exec sp_`/`xp_`, паттерны слепых boolean-инъекций `' OR '1'='1`, `LOAD_FILE()`/`INTO OUTFILE` | Critical |
| **command_injection** | Команды в обратных кавычках, подкоманды `$()`, конвейерное исполнение через pipe, reverse shell `/dev/tcp`, PHP-функции `passthru()`/`shell_exec()`/`system()`, вызовы `cmd.exe`/`powershell` | Critical |
| **nosql_injection** | Операторы MongoDB `$ne`/`$gt`/`$regex`/`$where`, инъекция `$or`, обход аутентификации `{"$gt": ""}` | Critical |
| **ldap_injection** | Операторы фильтров `(&` `(|` `(!`, перечисление атрибутов `*(cn=`, инъекции `objectClass`/`uid` | High |
| **xpath_injection** | Обход boolean `' or '1'='1`, инъекция функции `' or true()`, обход узлов `'] | '` | High |
| **jndi_injection** | `${jndi:ldap://`, обфускация `${lower:j}`, обфускация `${upper:j}`, обфускация пустой строкой `${::-j}`, поиск переменных окружения `${env:}`, системные свойства `${sys:}` | Critical |
| **ssi_injection** | Выполнение команд `<!--#exec cmd=`, включение файлов `<!--#include file=`, вывод переменных `<!--#echo var=`, информация о файлах `<!--#fsize`/`<!--#flastmod` | High |
| **graphql_injection** | Интроспекционные запросы `__schema`/`__type`, DoS через глубокую вложенность (≥5 уровней) | Medium |
| **ssti** | Jinja2 `{{}}`, FreeMarker `${}`, ERB `<%=` `<%@`, Velocity `#set()`, побег из песочницы через Python MRO `__mro__`/`__subclasses__()` | Critical |

### Протокольные атаки и атаки на запросы (9 детекторов)

| Детектор | Покрываемые паттерны | Серьёзность |
|----------|----------------------|-------------|
| **ssrf** | Облачные метаданные `169.254.169.254`, внутренние IP RFC1918 (10.x, 172.16-31.x, 192.168.x), loopback `127.x`, IPv6 loopback `::1`, `0.0.0.0`, опасные протоколы `gopher://`/`dict://`/`ftp://`/`file://` | Critical |
| **xxe** | Объявления сущностей `<!ENTITY`, внешние ссылки `SYSTEM`/`PUBLIC`, параметрические сущности `%`, объявления DTD `<!DOCTYPE` | Critical |
| **header_injection** | CRLF через URL-кодирование `%0d%0a`, инъекция сырого CRLF `\r\n` | High |
| **host_header** | Инъекция множественных Host-заголовков, отравление `X-Forwarded-Host`/`X-Original-URL`/`X-Rewrite-URL`, Host с CRLF | High |
| **request_smuggling** | Двойной заголовок `Transfer-Encoding`, контрабанда через `Content-Length: 0`, путаница завершения chunked `\r\n0\r\n` | High |
| **open_redirect** | Протокол-относительные URL `//evil.com`, переходы по псевдопротоколам `javascript:`/`data:text/html` | Medium |
| **cors** | Обход через `Origin: null`, комбинация `Access-Control-Allow-Origin: *` + Credentials | Medium |
| **websocket** | Рукопожатие `Upgrade: websocket`, кросс-доменный WS с `Origin: null`, открытое соединение `ws://` | High |
| **dns_rebinding** | Host-заголовок с внутренними IP `127.x`/`10.x`/`192.168.x`/`172.16-31.x`, `localhost`, `::1`, `0.0.0.0` | High |

### Атаки на данные и сериализацию (5 детекторов)

| Детектор | Покрываемые паттерны | Серьёзность |
|----------|----------------------|-------------|
| **deserialization** | PHP-объекты сериализации `O:число:`/`C:число:`, массивы `a:число:{`, вызовы `unserialize()`, магические методы `__wakeup`/`__destruct`/`__toString` и др. | Critical |
| **csv_injection** | Символы формул `=`/`+`/`-`/`@` в начале строки, DDE (динамический обмен данными), командный конвейер `cmd|`, функция `@SUM()` | Medium |
| **mail_header** | Инъекция скрытой копии `Bcc:`/`Cc:`, множественные отправители `From:`, инъекция MIME-заголовков `MIME-Version:`/`Content-Type: multipart`, манипуляция границей `boundary=` | Medium |
| **jwt_attack** | Обход через пустой алгоритм `alg: none`, обход пути через `kid`, пустой сегмент подписи, пустой сегмент payload | High |
| **prototype_pollution** | Загрязнение цепочки прототипов `__proto__`/`constructor.prototype`, перехват свойств `__defineGetter__`/`__defineSetter__`/`__lookupGetter__`/`__lookupSetter__` | High |

### Файлы и чувствительные данные (3 детектора)

| Детектор | Покрываемые паттерны | Серьёзность |
|----------|----------------------|-------------|
| **path_traversal** | Обход каталогов `../`/`..\\`, обход через URL-кодирование `%2e%2e`, обёртки протоколов `php://filter`/`php://input`/`phar://`/`zip://`/`data://`/`expect://`/`glob://`, усечение нулевым байтом `%00` | Critical |
| **upload** | PHP-теги `<?php`/`<?=`, ASP-теги `<%@`/`<%=`, паттерны бэкдоров `eval($_`/`system($_`/`exec($_`/`passthru($_`, суперглобальные переменные `$_GET`/`$_POST`/`$_REQUEST`/`$_SERVER`, обход через `base64_decode()` | Critical |
| **data_leak** | PAN кредитных карт из 16 цифр (Visa/MasterCard/AmEx/Discover/JCB/Diners), AWS Access Key `AKIA...`, заголовок PEM-приватного ключа `-----BEGIN`, API-ключи OpenAI/LLM `sk-...`, строки подключения к БД `mongodb://`/`mysql://`/`postgresql://`/`redis://`/`jdbc:`, JWT-токены | Critical |

## Использование

Готово к использованию без настройки:

```rust
use security_rust::Scanner;

let scanner = Scanner::default();
let results = scanner.scan("<script>alert('xss')</script>");
// [CRITICAL] XSS cross-site scripting detected — offset: 0, pattern: <script>
```

Полный справочник API (установка, выборочное сканирование, пользовательская настройка, отображение серьёзности, производительность) см. в [Справочнике API](./API.md).
